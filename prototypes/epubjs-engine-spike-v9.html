What can this prototype prove—and what remains unverified?

This is a separate adapter experiment that uses EPUB.js 0.3.93 and JSZip 3.10.1 loaded from pinned CDN URLs. Its controls are built from the EPUB.js published rendering/navigation API.

  • To try: import an original fixture, use the Contents list, change layouts, adjust type size, and navigate. The reader saves a CFI location in browser storage where permitted.
  • Unverified: full renderer runtime in this execution environment, restart durability, production CSP/security hardening, accessibility, RTL/Indic scripts, EPUB conformance and CFI migration from v7.
  • No imported EPUB file or personal note is sent to the FOLILUNE backend—there is no backend. Do not test confidential books in experimental software.

FOLILUNE © 2026 · Original interface concept. EPUB.js and JSZip are third-party open-source libraries used here for technical evaluation. Only original or legitimately obtained DRM-free publications should be imported.
